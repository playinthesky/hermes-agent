3. AI 작동 방식

3.1 전제 (특허·변리사 대응)

새로운 AI 모델을 만든 것이 아니라, 사전학습 LLM과 음성인식(ASR) 을 토론 진행 맥락에서 조건화·연쇄·배치한 시스템/방법이 발명. 신규성은 *모델*이 아니라 *운용 구조*에 있음.

3.2 도입 AI 기능 4종 (기호)

기호AI 기능(기술명)입력 → 출력
Ⓐ음성인식 (ASR/STT)음성 → 텍스트
Ⓑ대상 조건화 입장·논증 추출 (target-conditioned stance detection + argument mining)(쟁점+발언) → 관점·입장·맥락·요약(JSON)
Ⓒ의미 군집·토픽 도출 + 추상 요약발언 집합 → 쟁점별 토픽 3~5개
Ⓓ제어된 자연어 생성입론 분석 누적 → 상호토론 쟁점·질문
∅(AI 아님) 규칙·알고리즘배정·수치집계

3.3 작동 흐름

말   →  [Ⓐ 음성인식]   →  글
글   →  [Ⓑ 구조화 분석] →  입장·관점·맥락·요약   (개별 = 미시)
모음 →  [Ⓒ 집계·군집]   →  분포 % + 주요 토픽      (전체 = 거시)
종합 →  [Ⓓ 쟁점 생성]   →  상호토론용 쟁점·질문    (지향)
       └─ Ⓐ~Ⓓ 모두 "토론 쟁점"을 공통 기준으로 공유 ─┘

6. 해외 확장(Export) 추가요건 [지향]

국외 수출 시 기존 기능에 다언어 AI · 현지화 · 규제 · 글로벌 인증/결제 · IP 가 추가됨.

6.1 다국어 AI *(핵심, 특허가치 큼)*

  • Ⓐ 다국어 음성인식 — ko-KR 고정 → 대상국 다중 로케일(en/ja/fr…)
  • Ⓑ 교차언어 입장·논증 추출 (cross-lingual stance detection) — 언어가 달라도 쟁점 기준 동일 판정
  • Ⓒ 다국어 토픽 군집 — 혼합 언어 발언 의미 군집
  • Ⓓ 다국어 쟁점 생성
  • 🆕 실시간 번역 — 다언어 혼합 토론 상호 번역

6.2 UI·형식 현지화 (i18n/L10n)

  • 화면 다국어, 날짜·시간대·통화·숫자 형식, RTL 레이아웃

6.3 다양성 배정 축 현지화 (∅)

  • 기본축(성별·연령·지역)은 보편 / 국가별 추가축: 미국=인종·민족, 유럽=국적·언어, 종교·소득 등
  • 랜덤배정 "심화 축"을 국가 프로파일로 구성 가능하게

6.4 규제·데이터 주권

  • GDPR(EU)·각국 개인정보법(동의·삭제권), 데이터 레지던시(리전별 저장), 접근성(WCAG/ADA/EU AA)

6.5 인증·결제 글로벌화

  • 로그인: 카카오·네이버(국내) → Google·Apple·Microsoft·SSO
  • 결제: 포트원(국내) → Stripe 등 국제 PG, 다통화·VAT
