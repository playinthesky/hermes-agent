## 기준 1 — 표준업무의 챕터·파트 계량화 (케이스별 정리)

**측정**: 커버리지 = SOP·스킬·템플릿이 커버하는 파트 수 / 전체 파트 수

### 챕터×파트 구조 (8챕터 34파트)

| ID | 챕터 | 파트 | 기존 자산 |
|---|---|---|---|
| 1-1~4 | 수주 | RFP 감시 / 제안서 / 산출내역서(견적) / 프레스킷 | SOP-004 · PR#3 · PR#6 |
| 2-1~3 | 계약·착수 | 계약유형 판별 / 킥오프 / 역할 편성 | 프레스킷 트리거 |
| 3-1~5 | 공론 설계 | 의제 분석 / 이해관계자 맵 / 숙의 방식 선택(공론조사·시민배심·워크샵·토론회) / 공정성 설계(검증위 구조) / 일정·예산 설계 | — |
| 4-1~4 | 참여자 모집 | 표집 설계(층화추출) / 모집·1차조사 / 참여단 확정 / 안내·오리엔테이션 | AI-BDL 랜덤배정 |
| 5-1~6 | 숙의 운영 | 자료집(균형 검증) / e-러닝·정보 제공 / 입론 / 소그룹 토론(퍼실리테이션) / 전문가 패널 질의 / 조사(2~4차) | AI-BDL 입론·상호토론 · PR#3 인력구조 |
| 6-1~4 | 분석·집계 | 의견 변화 분석 / 논증 추출 / 군집·토픽 / 통계 검증 | AI-BDL Ⓑ·Ⓒ |
| 7-1~4 | 보고·권고 | 결과보고서 / 정책권고안 / 인포그래픽 / 보도자료·발표 | — |
| 8-1~4 | 회고·적립 | 프로세스 평가(OECD 가이드라인) / 백서 / 아젠다 적립 / 스킬화·SOP 개정 | SOP-002·003 |

### 의제화 판단 3기준 (파트 3-1 · 5-3 · 5-4 필수 적용)

> 출처: 코리아스픽스 퍼실리테이터 2급 워크북. 의제 선정과 토론 문항·옵션 설계 시
> 세 기준을 **모두** 채점하고 기록한다. 하나라도 생략한 설계는 미완성으로 간주한다.

| 기준 | 묻는 것 | 탈락 신호 |
|---|---|---|
| **시의성** | 지금 이 시점의 여론·제도·시장 상황과 맞닿아 있는가 | 근거 데이터(여론조사·통계)를 못 붙이면 탈락 |
| **대립성** | 실제로 의견이 갈리는 단층선 위에 있는가 | 아무도 반대하지 않는 항목은 죽은 선택지 |
| **공적 영향력** | 얼마나 많은 사람에게, 공동체 차원의 결정이 필요한 사안인가 | 사적 이익 프레임은 진단용으로만 허용, 숙의 의제 승격 시 배제 |

- 역할 분담: **진단 토론**은 인식 지형을 드러내는 게 목적이므로 공적 영향력이 낮은
  옵션도 (대립성이 높다면) 포함할 수 있다. **숙의 의제로 승격**할 때는 공적 영향력이
  1차 관문이다.
- 옵션 설계 절차: 이해관계자 역방향 매핑(누가 대변되는가) → 3기준 채점 → 공백·과대대표
  점검 → 트레이드오프(옵션 수 vs 집계 해상도) 명시 → 제외 항목과 사유 기록.

### 케이스 축 (챕터와 직교)

- **계약유형**: 공공입찰(RFP) / 수의 / 민간 / 정기 용역
- **의제 분야**: 에너지 · 도시 · 교육 · 보건 · 환경 · 기타
- **규모**: 소(~50명 워크샵) / 중(~100명) / 대(500명급 공론조사)
- **채널**: 대면 / 온라인(AI-BDL) / 혼합

**현재 점수: 약 20%** (34파트 중 자산 보유 7~8개)

## 기준 2 — 이해관계자 노드 간 대화의 전략·방식·매체

**측정**: 엣지 커버리지 = (전략·방식·매체·금기 4항 문서화된 엣지) / 전체 관리 대상 엣지

### 노드 (8)

① 발주처(담당 공무원) ② 공론화위·검증위 ③ 시민참여단 ④ 전문가·자문단
⑤ 이해당사자 그룹(찬/반) ⑥ 언론 ⑦ 일반 여론 ⑧ 내부 운영팀(퍼실·기술오퍼)

### 엣지 매트릭스 (컨설턴트 직접 엣지 7 + 중재 엣지)

| 엣지 | 전략 | 방식 | 매체 | 금기 (OECD 원칙 근거) |
|---|---|---|---|---|
| ↔발주처 | 근거 중심 보고, 기대치 관리 | 정기 보고회의+서면 | 공문·보고서·대면 | 중간 결과의 정치적 해석 제공 (염결성) |
| ↔공론화위·검증위 | 절차 정당성 입증 | 검증 요청·회의록 | 공식 문서 | 검증 절차 생략 (책무성) |
| ↔시민참여단 | 쉬운 언어, 절차 신뢰 형성 | 안내→학습→숙의→피드백 | 안내문·문자/앱(AI-BDL)·현장 | 특정 입장 유도 (정보·포용성) |
| ↔전문가·자문단 | 균형 패널 구성 | 자료집 감수·패널 질의 | 서면 감수·현장 | 한쪽 진영 전문가 편중 (대표성) |
| ↔찬/반 이해당사자 | **엄격한 대칭성** — 동일 정보·동일 기회 | 사전 협의+자료집 검증 참여 | 기록이 남는 공식 채널만 | 한쪽과의 비공개 단독 접촉 (투명성·염결성) |
| ↔언론 | 통제된 사실 전달 | 프레스킷+브리핑 | 보도자료·프레스킷(PR#6) | 결과 예단성 발언 (투명성) |
| ↔내부 운영팀 | 명확한 지시·중립 훈련 | 브리핑 킷+리허설 | 매뉴얼·현장 무전 | 조별 진행 편차 방치 (집단숙의) |
| 중재: 언론↔참여단 | 참여단 보호 | 인터뷰 규칙 사전 합의 | 위원회 경유 | 개별 참여자 노출 (프라이버시) |

**설계 원칙**: 엣지 관리의 목표는 설득이 아니라 **공정성이 기록으로 증명되는 것**.
비대칭 접촉 1건이 절차 전체의 정당성을 무너뜨린다.

**현재 점수: 약 10%** (언론 엣지 반쪽 + 내부 통신만 존재)

## 기준 3 — 리소스 모집·관리·온보딩

**측정**: 6단계 × (절차 문서화/데이터/자동화) 3항 = 18칸 체크

### 단계 구조

```
수요 산정 → 모집 → 확정·계약 → 온보딩 → 운영 관리 → 정산·평가
```

- **수요 산정**: 산출내역서 인력표(PM·리딩퍼실·그룹퍼실 N·기술오퍼)에서 규모별 표준 편성 자동 도출 — 규모 축(기준 1)과 연동
- **풀 레지스트리**: 프로필(등급·지역·경력·단가·가용성·평가이력) 스키마만 본 저장소에 정의, **데이터는 비공개 저장소 분리** (개인정보)
- **온보딩(핵심)**: 프로젝트 확정 시 지능이 **퍼실리테이터 브리핑 킷** 자동 생성 — 의제 요약(CH3 산출물) + 이해관계자 지도·금기(기준 2) + 조별 진행 스크립트 + 중립성 준수 서약 + 리허설 체크리스트
- **평가 기준**: IAF 6대 역량(협력관계 구축 / 프로세스 설계 / 참여 환경 조성 / 결과 도출 유도 / 전문지식 유지 / 전문가 태도)을 평가표로 사용, 평가 결과는 풀 레지스트리로 되먹임(다음 모집 우선 추천)

**현재 점수: 약 10~15%** (인력표·교보재 항목·AI 캠프 온보딩 체계만 존재)

## 기준 4 — 단계별 산출물의 인지와 형식 제공

**측정**: 챕터별 필수 산출물(약 25종) × (정의/템플릿/자동화) 3단계 = 75칸

### 산출물 맵

| 챕터 | 필수 산출물 | 정의 | 템플릿 | 자동화 |
|---|---|---|---|---|
| CH1 | 제안서 · **산출내역서** · 프레스킷 | ◑ | ◑ (산출내역서 완비) | ◑ |
| CH2 | 계약 검토서 · 착수보고 | ✘ | ✘ | ✘ |
| CH3 | **공론 설계서** · **숙의 자료집**(찬반 균형 검증본) · 검증계획 | ✘ | ✘ | ✘ |
| CH4 | 표집 설계서 · 모집 공고 · 참여자 안내문 | ✘ | ✘ | ✘ |
| CH5 | 진행 시나리오 · 조별 기록지 · e-러닝 콘텐츠 · 속기록 | ✘ | ✘ | ✘ |
| CH6 | 의견변화 분석 · 논증 지도 · 통계 검증 보고 | ✘ | ✘ | ✘ |
| CH7 | **결과보고서** · 정책권고안 · 인포그래픽 · 보도자료 | ✘ | ✘ | ✘ |
| CH8 | 평가보고(OECD 항목) · 백서 · 아젠다 항목 | ◑ | ◑ | ◑ |

- **실물 참조 세트**: 신고리 공론화가 공개한 문서 일습(자료집, e-러닝, 백서 「숙의와 경청」, 권고안)을 각 산출물의 품질 기준 예시로 사용한다.
- **공략 패턴**: PR#3에서 증명된 4종 세트(TEMPLATE + WORKFLOW 가이드 + 렌더러 + 스킬)를 문서 유형별로 복제한다. 형식 공통 인프라(AX 디자인 시스템, 파일명 `YYMMDD_Fb_제목 vX.Y.Z`, HTML→PDF 파이프라인)는 이미 존재.
- **우선순위**: 결과보고서 → 공론 설계서 → 숙의 자료집 (사용 빈도 × 공백 크기)

**현재 점수: 약 25~30%**
