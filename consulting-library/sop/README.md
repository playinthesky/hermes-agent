## 문서 체계 (SOP / WI / Form / Record)

표준 SOP 관행에 따라 4계층으로 구분합니다.

| 계층 | 정의 | 이 도서관에서 |
|------|------|---------------|
| **SOP** | 무엇을·누가·언제 하는지 정한 표준절차 | `sop/SOP-***.md` |
| **WI (작업지시)** | 한 단계를 어떻게 수행하는지의 세부 지침 | `intake/triage-guide.md` |
| **Form (양식)** | 절차 수행 시 채우는 빈 서식 | `templates/planning-document.md`, `templates/agenda-entry.md` |
| **Record (기록)** | 절차 수행으로 생성된 산출물·증적 | 작성된 기획문서, `agenda` GitHub 이슈, `playbooks/` 샘플 |

## 표기 규칙

- **문서번호**: `SOP-NNN` (3자리, 발번 순). 폐기해도 번호 재사용 금지.
- **버전**: `vMAJOR.MINOR`. 절차 단계 변경=MAJOR, 문구/링크 수정=MINOR.
- **개정 이력**: 각 SOP 하단 표에 버전·일자·변경요약·작성자 기록.
- **역할 약어**: CON(컨설턴트, 주관) · REV(리뷰어, 검수) · LIB(도서관 관리자, 적립·인덱스).
- **상태**: `초안` → `발효` → `폐기`.

## 신규 SOP 추가 절차

1. 다음 번호로 `SOP-NNN-<slug>.md`를 [표준 섹션](#표준-섹션-구성)에 맞춰 작성한다.
2. 위 **SOP 목록** 표에 한 줄 추가한다.
3. 관련 WI/Form이 있으면 해당 파일과 상호 링크한다.

## 표준 섹션 구성

모든 SOP는 다음 순서를 따른다:
`1. 목적 · 2. 적용 범위 · 3. 용어 정의 · 4. 역할 및 책임 · 5. 절차 · 6. 기록물 · 7. 관련 문서 · 8. 개정 이력`
