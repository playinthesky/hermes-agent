# 산출내역서 작성 워크플로우 (코리아스픽스 / fKF · AX 디자인)

참여형 워크샵·공론화 사업의 **산출내역서(견적서)** 를 AX 디자인 시스템으로
빠르게 만들기 위한 가이드다. 우송대학교 AI 교수 워크샵 건으로 한 사이클을
돌며 수렴한 규칙을 정형화했다.

## 구성 파일

| 파일 | 용도 |
|------|------|
| `TEMPLATE.html` | 빈 산출내역서 템플릿. `{{...}}`·`.fill`이 가변부 |
| `render_pdf.js` | HTML → PDF (A4·2cm 여백·하단 중앙 페이지번호) |
| `build_standalone.py` | CSS 인라인 + 이미지 base64 → 단일 HTML 다운로드본 |
| `../colors_and_type.css` | AX 디자인 토큰 (공용, 수정 금지) |
| `../bdlee.jpg` | 퍼실리테이터 인물 사진 (공용) |

완성 예시: [`../우송대_AI교수워크샵_산출내역서.html`](../우송대_AI교수워크샵_산출내역서.html)

## 1. 입력 체크리스트 (작성 전 수집)

- **발주 주체** — fKF / 코리아스픽스 중 어디로 문의가 들어왔나 (표지·Contact 주체 결정)
- **발주처 / 사업명 / 사업 부제**
- **일시·장소 / 규모·편성** — 인원, 조 편성 수
- **진행 방식** — 기조강연·분임토의·발표·투표·시상 등
- **운영 인력 구성과 단가** — 역할별 인원 + 월급여 대비 투입율(M/M)
- **직접경비** — 기획 운영비(답사·회의), 교보재 진행비(마스터·운영키트·소모품)
- **제공 산출물** — 사전설문, 교보재, 진행자료, 결과보고서 등 (각각 포함/옵션 구분)
- **불포함(발주처 직접 집행)** — 식음·시상·장소·기본 장비·인쇄·행정인력 등
- **옵션 항목** — 정식 결과보고서 등 협의 시 추가될 항목과 금액
- **목표 총액** (있으면) — VAT 포함/별도 명확히
- **퍼실리테이터 약력** — 현직/전직/자문/저서 구분
- **연락처** — TEL·MAIL

## 2. 산정 규칙

1. **역할분담형** — 발주처가 직접 집행하는 분(식음·시상·장소·기본 장비·인쇄·행정)은
   §4 합계에서 **제외**하고 §4.2 "불포함 사항"에 별도 표기. §1 callout에 범위를 명시.
2. **인건비 = 월급여 대비 투입율(M/M)** — 1일 행사라도 준비·운영 공수를 M/M로 산정.
   코드 `F-xx`. 동일 역할 다인은 `수량 × 단가`로.
3. **직접경비** — 기획 운영비(C-01), 교보재 등 진행비(C-02)를 "식(式)"으로. 코드 `C-xx`(gold).
4. **산출물** — 코드 `D-xx`(teal). 인력비에 포함되면 금액 `0`,
   별도 청구면 금액, **옵션이면 금액 0 + 비고에 "협의 시 +금액(옵션)"**.
   옵션 금액은 기본 합계에 넣지 않는다.
5. **목표 총액 역산** — 총액을 맞춰야 하면 PM 기획·설계비(F-01) 또는
   기획 운영비(C-01)로 차액을 흡수. 흡수 라인은 ev에 근거를 적는다.
6. **VAT** — 공급가액 × 10%. 표지·총괄집계 모두 "공급가 / VAT / 총견적" 3단 일치.
7. **끝자리 정리** — 총견적은 만원 단위로 떨어지게 (예 8,140,000). 검산 필수.

## 3. 작성 규칙 (톤·브랜딩)

- **주체 표기는 발주 경로대로** — fKF 문의면 표지 logotype·§4 callout·Contact 모두
  fKF 우선(코리아스픽스 병기). 코리아스픽스 문의면 순서 교체.
- **본문은 명사형** — "~한다/~이다" 평서문 지양. 리드 문단이 군더더기면 표·callout만 남기고 삭제.
- **불필요한 영어 라벨 금지** — 핵심 용어만 한·영 병기(.ohi 칩의 EN 등). 장식용 영문은 빼기.
- **선택 섹션** — 토의형이 아니면 §2(토의 프레임)는 통째로 삭제 가능.

## 4. 작성 → 렌더

```bash
# 1) 템플릿 복사 후 {{...}}·.fill 채우기
cp _workflow/TEMPLATE.html "발주처_사업명_산출내역서.html"
#    링크 경로 주의: TEMPLATE 은 ../colors_and_type.css / ../bdlee.jpg 를 참조.
#    proposals/ 루트로 옮기면 ../ → ./ 로, 즉 colors_and_type.css / bdlee.jpg 로 고친다.

# 2) PDF 렌더 (A4·2cm 여백·하단 중앙 "n / total")
node _workflow/render_pdf.js "발주처_사업명_산출내역서.html" "발주처_사업명_산출내역서.pdf"
#    크롬 경로가 다르면: CHROME=/path/to/chrome node _workflow/render_pdf.js ...

# 3) 단일 HTML 다운로드본 (CSS 인라인 + 이미지 임베드)
python3 _workflow/build_standalone.py "발주처_사업명_산출내역서.html" "발주처_사업명_산출내역서_standalone.html"
```

## 5. 검토 체크리스트 (배포 전)

- [ ] **합계 검산** — 공급가 × 1.1 = 총견적, 표지·§4·§4.1 세 곳 금액 일치
- [ ] **§4 한 페이지** — 인쇄 시 산출 표 + §4.1 총괄집계가 한 페이지에 (`.cost-keep`)
- [ ] **페이지 연속** — 빈 페이지·어색한 분할 없음 (PDF로 실제 확인)
- [ ] **좌측 여백** — 스파인과 본문 간격 정상 (인쇄 시 `.pad` 26px)
- [ ] **주체 일관성** — 표지·callout·Contact의 fKF/코리아스픽스 순서 일치
- [ ] **오탈자** — 발주처명·사업명·금액·연락처
- [ ] **`.fill` 잔재** — 채우지 않은 `{{...}}` 없음 (화면엔 노랗게 보이고 인쇄 시 사라지므로 화면에서 점검)
